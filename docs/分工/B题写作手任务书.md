# 2026 电工杯 B 题写作手任务书

## 1. 角色定位

写作手负责把建模逻辑、代码结果和图表组织成评委能快速理解的论文。写作手不是最后才排版的人，而是从开赛早期就要建立论文骨架、术语表和图表位置。

## 2. 总体交付

写作手应交付：

1. 论文主文档。
2. 摘要与关键词。
3. 问题重述。
4. 模型假设与符号说明。
5. 数据预处理说明。
6. Q1-Q4 模型、结果和分析章节。
7. 模型评价、局限性和改进方向。
8. 图表编号、公式编号、参考文献与附录整理。

## 3. 写作原则

### 3.1 结果驱动

论文的核心段落应围绕：

- 题目规则。
- 自己的模型。
- 自己算出的结果。
- 对结果的解释。

少写空泛套话，多写数据、公式和模型选择理由。

### 3.2 术语统一

统一使用：

- 理论服务需求。
- 消费约束后需求。
- 实际有效服务人次。
- 服务覆盖率。
- 综合满意度。

避免同一指标在不同章节换多个名字。

### 3.3 论文语言与队内语言分开

不要把队内作战词汇直接放入论文，例如：

- 预算墙。
- 防爆破。
- 死命令。
- 刚性冻结。
- 一键重演。

论文改用：

- 预算约束剪枝。
- 容量可行性校验。
- 固定站点方案。
- 场景重算。

## 4. 论文结构建议


## 5. 阶段 0 任务：先写不会被结果阻塞的部分

### 5.1 必写章节

- 问题重述。
- 问题分析初稿。
- 模型假设。
- 符号表模板。
- 数据预处理章节骨架。

### 5.2 需要向建模手索取

- 假设列表。
- 符号定义。
- 各问题模型路线。

### 5.3 需要向编程手索取

- 数据表字段说明。
- 数据清洗规则。
- 预处理后的覆盖矩阵描述。

## 6. 阶段 1 任务：Q1 章节

### 6.1 必写内容

1. 老人健康状态递推模型。
2. 新增项、死亡项和转移项解释。
3. 理论需求计算。
4. 消费约束比例削减。
5. 第 5 年需求结果分析。

### 6.2 推荐图表

| 图表 | 用途 |
| --- | --- |
| 各小区第 5 年老人结构表 | 回答 1.1 |
| 三类老人数量变化图 | 展示预测趋势 |
| 第 5 年服务需求热力图 | 展示需求差异 |
| 理论需求与消费约束后需求对比图 | 展示消费约束影响 |

### 6.3 重点避免

- 不把消费约束后需求写成满意度折减后的有效服务人次。
- 不把人口预测写成无新增、无死亡的普通转移模型。

## 7. 阶段 2 任务：Q2 章节

### 7.1 必写内容

1. 选址模型定位。
2. 决策变量。
3. 预算、半径、容量约束。
4. 覆盖率与满意度目标。
5. 求解算法与时间复杂度。
6. 最优站点方案。
7. 年度利润、覆盖率、各小区满意度。
8. 至少 3 点局限性与改进方向。

### 7.2 推荐图表

| 图表 | 用途 |
| --- | --- |
| 站点布局表 | 回答站点位置和规模 |
| 小区归属网络图 | 展示覆盖关系 |
| 站点容量利用率表 | 证明容量可行 |
| 小区满意度表 | 回答题目要求 |
| 年利润表 | 回答题目要求 |

### 7.3 结果解释重点

- 为什么该布局能兼顾覆盖率和满意度。
- 哪些小区受距离约束影响较大。
- 容量与建设预算是否形成主要限制。

## 8. 阶段 3 任务：Q3 章节

### 8.1 必写内容

1. 问题 2 站点方案固定说明。
2. 5 项付费服务定价变量。
3. 紧急救助免费说明。
4. 价格满意度分段规则。
5. 政府补贴上限。
6. 利润率约束。
7. 最优价格结果。
8. 各站利润率与小区满意度。
9. 三类老人服务可及性分析。

### 8.2 推荐图表

| 图表 | 用途 |
| --- | --- |
| 最优定价表 | 回答 3.2 |
| 补贴表 | 展示财政约束 |
| 利润率表 | 展示保本微利 |
| 价格满意度与总满意度表 | 回答题目 |

### 8.3 可及性分析写法

可从三维写：

1. 经济可及性：价格与消费能力。
2. 地理可及性：站点距离与覆盖半径。
3. 服务可及性：站点容量、响应满意度、服务类型匹配。

## 9. 阶段 4 任务：Q4 章节

### 9.1 必写内容

- 三个题设扰动场景。
- 基准与扰动结果对比。
- 站点、价格、补贴、覆盖率、满意度变化。
- 敏感性与鲁棒性评价。
- 现实不确定性及应对建议。

### 9.2 推荐图表

| 图表 | 用途 |
| --- | --- |
| 场景对比总表 | 全局总结 |
| 覆盖率与满意度变化图 | 指标变化 |
| 补贴与利润率变化图 | 财政和经营变化 |
| 站点方案变化表 | 网络稳定性 |

## 10. 摘要写作任务

摘要建议最后完成，但要提前留出结构：

1. 背景一句。
2. 对问题 1 使用何模型，得到何类结果。
3. 对问题 2 使用何优化方法，得到何方案。
4. 对问题 3 如何定价与补贴，得到何结论。
5. 对问题 4 得到何鲁棒性结论。

摘要必须含结果，不只写“建立了模型”。

## 11. 与其他角色的接口

### 11.1 向建模手确认

每个公式段落写完后确认：

- 符号是否一致。
- 假设是否被夸大。
- 局限性是否准确。

### 11.2 向编程手确认

每张结果表进入论文前确认：

- 单位。
- 场景。
- 指标口径。
- 数字是否为最新版输出。

- [ ] 算法复杂度在 Q2 有说明。
- [ ] Q3 单独列出价格满意度。
- [ ] Q4 三个题设场景分别比较。
